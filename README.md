# Niche Video Generation Opportunities

一份关于小众、可落地视频生成商业场景的中文研究报告，覆盖：

- 设备售后与维修视觉指引
- 连锁服务业分支式冲突培训
- 公共信息手语视频本地化
- 博物馆历史人物叙事重制
- 特殊教育个性化 Social Story 视频
- 罕见事故与边缘事件安全训练

同时包含 Soap2Soap、MovieAgent、ShowHowTo、Neural Sign Actors、SS-Bench、VideoDirectorGPT 和 Cosmos-Drive-Dream 等论文解读。

## 在线阅读

启用 GitHub Pages 后访问仓库的 Pages 地址。

## 本地阅读

直接打开 `index.html`，或在目录中运行：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000/`。

## 说明

本项目用于研究和机会筛选。商业案例数字来自公开供应商案例；论文指标来自论文原文。报告不构成市场规模预测、医疗建议或安全操作规范。
